# Work-terms dataset

Named public work-platform terms with versions, invalidation, attribution,
and explicit republication rights.

Maintainer pack: `packs/work-terms-dataset`.

This dataset is not a complete or universal corpus of work terms.
It does not scrape. Private and auth-gated terms are refused.

```
node packs/work-terms-dataset/bin/work-terms.mjs verify
```
