# Finite changed-source maintenance delivery — 244005

A source/task/version-bound assessment becomes one reviewed handback, persisted
in the **current Neo machine-gateway's existing SQLite WAL receipts**. This
package mounts free provider operations in the existing SameDayDesk Node host.
Root receives the source; it has not installed a public maintenance service.

The executable acceptance changes an owner-controlled JSON file while its HTTP
origin is running, captures its exact bytes, runs `source-change-alert` through
the E11 occurrence template, compares the selected fields with the mounted
merchant C31 implementation, projects through existing result-reuse, submits an
explicit authorized review, restarts the API and reads the same durable handback
from another consumer process. It supplies current descriptor, rights and
reviewer files explicitly. The specimen is local owner QA, not customer demand.

Work delivered is the factual changed-source assessment and actionable handback.
**E02's reviewed repair artifact is not supplied.** No repair is executed or
represented as accepted. E11's historical `repair` disposition remains inside
the unmodified template evidence; the outer delivery calls the work
`bounded_assessment`, and acceptance names that scope precisely.

```sh
# Use the exact dependency-ready mounts in INSTALL.md.
flock /home/ubuntu/.cache/pilot-ae18-build.lock \
  node tools/ae18-maintenance-delivery/bin/accept.mjs /absolute/evidence.json
flock /home/ubuntu/.cache/pilot-ae18-build.lock \
  node --test --test-concurrency=1 tools/ae18-maintenance-delivery/test/*.test.mjs
```

One assessment and one review phase are admitted per configured occurrence.
Same-key retry uses gateway replay. A different key reads the first completed
phase's output; a different payload conflicts. An interrupted/failed first
phase is reconciled rather than rerun. Gateway call usage counts transport
admissions; it is not paid-task count. Both route prices and payment budgets are
zero. The handback creates no capture, obligation, payment, repair execution,
subscription, queue or second paid task.

An unchanged selected source is `not_yet_due`. Stale priors and partial fields
cannot become accepted useful work. Current read/reuse rights can yield useful
no-fit without reading restricted content. Review rights, mandate revocation,
and expiry are evaluated again when review is submitted. A reviewer can accept
a rights no-fit without obtaining reuse rights. Unknown prior payment remains
`outcome_unknown`; the handback directs readback reconciliation, never a retry.

Prior payload digest, task and source identity are checked. Source bytes must
match the descriptor's supplied version. Source URLs and local paths come only
from deployment-owned config. A source version change requires a new occurrence
and immutable prior/descriptor; neither is overwritten. Retained result
entitlement is explicit and never inferred from a schema or payment receipt.
Result-reuse output remains user-selected unverified evidence with no public-safe
certification or automatic permission grant.
