# AGL seed loop, 2026-11-04

A distinct caller can read the accepted query-key artifact from the ordinary SDS machine instructions, run the published query-key 1.1.0 command, and offer a changed pair back through the existing interest route.

The saved public GET fixtures remain schema_unlinked. This branch links the schema in the SDS producers only. It does not deploy.

Normal next use, against an origin that serves this branch:

```
node experiments/agl-seed-loop-20261104/cold-caller.mjs --origin https://HOST --ca-file CA
```

The machine instructions themselves name the acquire and apply commands. A private field, an unknown key, or an unknown schema stops before a digest and before `execute.py`.
