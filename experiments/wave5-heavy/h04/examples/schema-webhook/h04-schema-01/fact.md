Draft 04 JSON Schema meta-schema types `exclusiveMinimum` as a boolean (`true` means “greater than `minimum`”); Draft 06 retargets the same keyword to type `number` (the exclusive bound itself). A consumer that still serializes `exclusiveMinimum: true` against a Draft 06+ meta-schema is now invalid, so callers who pin `/properties/exclusiveMinimum` must update emitters and validators.
