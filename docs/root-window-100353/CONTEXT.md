artifact, and optionally leaves an authorized improvement. A different later

delivery path and current provenance. It is not the number of features, agents,
forum views or archives. The next outcome is one actual outside task completed
through a public client, followed by a separately observed useful paid operation
or later reuse. Build cheap useful experiments before demand, but do not infer

## Structural contracts and implementation order

1. **Task intent:** caller task id, exact operation/input, required useful output,
   optional retained/share purpose, explicit execution limits. A label alone
   neither funds work nor proves ownership. Do not substitute fixed examples.
2. **Acquisition:** current machine entry points to exact licensed bytes and a
   supported runtime. Frozen archives retain historical facts; the current
   sidecar states what was actually received. A failed setup returns one useful
   next action, not an invented successful invocation.
3. **Execution:** one deadline/body/output allowance covers setup and owned
   children. Preserve legitimate useful negatives and missing-input guidance.
   Record the output separately from caller-asserted usefulness.
4. **Authority and reuse:** use the already received owning operation/current
   evidence and purpose-bound grant. Reward settlement does not erase sharing;
   revocation/correction does. Whole reads and generation checks remain bounded.
5. **Commercial evidence:** reuse301's server-minted event-to-task seam and the
   existing outcome/settlement journals. Never join by wallet, digest, user agent,
   HTTP200 or a caller's trusted label. Missing sides stay unknown after crashes.
6. **Integration:** source receiving, production route, hosted archive, cold
   command and actual customer usefulness are separate observations. Small fixes
   are made by the receiving owner; preserve context for substantial redesign.

These are completion criteria for a reusable task lifecycle, not six new
microservices. Each package uses the existing implementation for every stage
that is already received and names only its residual seam.
