The public 0.3.1 client and its `aa861e98` descriptor are inputs. Their bytes are not rewritten. Acquire keeps comparing the live profile with that descriptor, so a candidate install fails acquisition closed until Root publishes a successor descriptor. Market readback does not use that source hash.

`vendor/hosted-wallet-market/src/native-debt.mjs` is outside the diff. The original obligation id `oobl_izUh7nn9vd_APjsR` stays in that constant. The synthetic store seeds `obl_legacy23410001` and must keep its authority-table digest across the upgrade and the code rollback.

Accepted money logic, the H113 and H115 result writers, the operator branch, public copy, live flags, and old terms are not writers of this package. A semantic money defect is exported as a countercase. It is not patched here.

No model child, paid provider call, or second parallel wallet is added. One serial contained run is the execution.
