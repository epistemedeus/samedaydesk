Read the homepage without a browser

The homepage is a plain document. The H1, the live merchant ticket, and Organization plus WebSite JSON-LD are in the first bytes of the response, with no JavaScript involved. There is no price table, no FAQ, and no comparison table on /.

curl -sS -A "YourAgent/1.0" https://samedaydesk.com/ | grep -o '<h1>[^<]*</h1>'

# structured data, generated from the same record the visible page is checked against
curl -sS https://samedaydesk.com/ \
  | sed -n '/application\/ld+json/,/<\/script>/p'

Free readiness endpoint

The crawler and structured-data checks behind the free report are a public JSON endpoint. No key, no account, no payment.

curl -sS "https://samedaydesk.com/api/tools/ai-readiness?url=https://example.com"

It returns the checks, what each one saw, and the concrete fix for each failure. The same checks run as a CLI and as a library from the public repository.

Homepage MCP is not the paid merchant

The Streamable HTTP MCP server at https://samedaydesk.com/mcp is the free AI-readiness and TaskMarket tool server. Live initialize reports samedaydesk-agent-tools version 1.2.0. It is not the 22-tool Base USDC merchant.

curl -sS -X POST https://samedaydesk.com/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"example","version":"0"}}}'

The answer panel behind the free report is deliberately not exposed here. It costs money per call, and an unauthenticated machine interface to it would be a budget hole rather than a feature.

Paid merchant

The live paid origin is https://agents.samedaydesk.com/. Read POST /mcp initialize for the live version. Count dual-rail products from the free catalog and MCP, not from raw x402 item length:

  • GET /api/actions: 22 paid actions on x402 and MPP.
  • POST /mcp unpaid tools/list: 22 tools. Do not call a paid tool from this page.
  • GET /.well-known/x402: 23 items because Circle Gateway is listed as an alternate x402 rail of the same payment-offer preflight product. It is not a 23rd MPP product.
  • GET /mpp-openapi.json: native MPP discovery. Circle Gateway is absent.
curl -sS https://agents.samedaydesk.com/api/actions
curl -sS https://agents.samedaydesk.com/.well-known/x402
curl -sS https://agents.samedaydesk.com/mpp-openapi.json

SDK notes for that gateway remain at /docs/x402-sdk/. The apex path /x402 is a leftover app-shell route, not the live manifest.

Buying the human services from software

There is no machine purchase path for the audit or the sprints, and we would rather say so than publish an endpoint that does not exist. Checkout is a form on each pay card that creates a Stripe session server side. Those pages are not the homepage offer. If you are an agent acting for an owner, send them the card:

  • /pay/audit
  • /pay/sprint

Verifying what this site claims

The published self-audit ships a replay script that re-tests its own findings against production and exits non-zero while any of them still hold. It is a frozen 2026-08-19 evidence pack, not the current homepage offer.

curl -sS https://samedaydesk.com/audit/samedaydesk/2026-08-19/replay.sh -o replay.sh
bash replay.sh ; echo "exit=$?"
