For agents

Documentation for software reading this site. Everything here is a real request you can run now. The human services and their prices are on the homepage; this page does not price anything.

Read the offer facts without a browser

The homepage is a plain document. The prices, the clocks, the comparison table, and every FAQ answer are in the first bytes of the response, with no JavaScript involved.

curl -sS -A "YourAgent/1.0" https://samedaydesk.com/ | grep -o '<h1>[^<]*</h1>'

# structured data, generated from the same record the visible page is checked against
curl -sS https://samedaydesk.com/ \
  | sed -n '/application\/ld+json/,/<\/script>/p'

Free readiness endpoint

The crawler and structured-data checks behind the free report are a public JSON endpoint. No key, no account, no payment.

curl -sS "https://samedaydesk.com/api/tools/ai-readiness?url=https://example.com"

It returns the checks, what each one saw, and the concrete fix for each failure. The same checks run as a CLI and as a library from the public repository.

MCP server

The same checker is available over Streamable HTTP MCP at https://samedaydesk.com/mcp. Point an MCP client at that URL; there is no key and no registration step.

curl -sS -X POST https://samedaydesk.com/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

The answer panel behind the free report is deliberately not exposed here. It costs money per call, and an unauthenticated machine interface to it would be a budget hole rather than a feature.

Paid data gateway

A separate service publishes pay-per-call data tools that settle in USDC on Base, accepting both x402 and native MPP. It has its own manifest, and that manifest is the count and the price list rather than a number written on this site.

curl -sS https://x402-url-extractor-production.up.railway.app/.well-known/x402

Human-readable notes on that gateway are at /x402, and the SDK reference is at /docs/x402-sdk/.

Buying the human services from software

There is no machine purchase path for the audit or the sprints, and we would rather say so than publish an endpoint that does not exist. Checkout is a form on each pay card that creates a Stripe session server side. If you are an agent acting for an owner, send them the card:

  • /pay/audit
  • /pay/sprint
  • /pay/sprint-plus

Verifying what this site claims

The published self-audit ships a replay script that re-tests its own findings against production and exits non-zero while any of them still hold.

curl -sS https://samedaydesk.com/audit/samedaydesk/2026-08-19/replay.sh -o replay.sh
bash replay.sh ; echo "exit=$?"
