What makes it maintainable

No-key baseline

The default build uses Solana JSON-RPC, DeFiLlama, CoinGecko, official Solana RSS, and GitHub's public API. A private RPC can be supplied without changing the code.

Partial truth beats complete fiction

Every source carries status, timestamp, latency, URL, and a bounded error. Missing metrics remain visibly unavailable.

Two kinds of anomaly

Fixed safety thresholds catch understood failure modes. Robust z-scores catch new deviations without letting one incident erase its own baseline.

One run, three audiences

Operators get a dashboard, researchers get Markdown, and software agents get the same facts as structured JSON.

Transparency: SameDayDesk is not affiliated with Solana Foundation, Superteam, DeFiLlama, or CoinGecko. This is an independently built public-data product and portfolio case study. Source-specific methodology and rate-limit risk are documented in the repository.
