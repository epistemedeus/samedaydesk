SkillGuard · SameDayDesk

Scan a skill, plugin, or MCP server before you install it.

SkillGuard is a free SameDayDesk command that reads the files and flags known-bad patterns. It never runs the code it inspects. No account is required for the free check.

npx github:epistemedeus/skillguard https://github.com/owner/repo

A local folder works too: npx github:epistemedeus/skillguard ./my-skill. Hooks are disabled on clone. The command never runs npm install or the target code.

What it checks

    
These are the checks published in the SkillGuard repository on GitHub.

    

      
CheckWhat it flags

      
        
env-exfilA sensitive environment variable read next to a network call

        
exfil-hostA hardcoded webhook, pastebin, raw IP, or Telegram exfil endpoint

        
obfuscationeval(atob(...)), curl | bash, or subprocess on encoded data

        
prompt-injectionData-exfil, ignore-instructions, or auto-approve text in SKILL.md, tool descriptions, or prompts

        
secret-literalAPI keys or private keys committed in the tree

        
committed-binaryCompiled ELF, Mach-O, or PE executables

        
forced-artifactA build step that generates and commits an encrypted blob

        
dangerous-permsAuto-approve-all, sandbox disabling, or --dangerously-skip-permissions

        
install-hookpreinstall or postinstall scripts that run on install

      
    

    
Exit codes: 0 clean, 2 suspicious, 3 dangerous, so CI can gate on the result. Heuristics catch known patterns. A novel attack can evade a static scan. This is a first check, not a guarantee.
