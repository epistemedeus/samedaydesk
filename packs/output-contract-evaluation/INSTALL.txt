SameDayDesk output-contract-evaluation (proposed)
=================================================

Required runtime: Node.js 22.x
No npm install. No archive. Not a live SKU.

From the repository root:

  node tools/output-contract-evaluation/cli.mjs evaluate --pretty --case packs/output-contract-evaluation/fixtures/invalid-output-settlement-preserved.json

  node tools/output-contract-evaluation/cli.mjs evaluate --pretty --seed void-settlement

  node --test tools/output-contract-evaluation/test.mjs

The CLI reads local JSON only. It does not fetch, charge, sign, or mutate
checkout, registry, or settlement. Invalid output preserves settlement.
Proposed price is 5.000 USDC and is not charged here.
